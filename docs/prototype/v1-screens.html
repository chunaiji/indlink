手机屏是按刻度画的，可直接换算成真机 pt。 屏宽 252px 对应 375pt 设备，比例 0.672；页面 CSS 变量 --t* / --r* / --s* 注释里标了对应 pt 值。 字号只用 11 / 12 / 13 / 15 / 17 / 20 / 24 / 28； 圆角按层级分 8 标签 · 12 按钮 · 16 卡片 · 20 大卡 · 28 模态 · 999 胶囊； 间距走 4pt 栅格，屏幕左右统一 16pt 一条竖线对齐。 可点区域高度最小 44pt——列表行、按钮、Tab 均按此下限。 全圆角胶囊另有一条宽高比下限：不低于 1.7 : 1——只卡最小宽度不够， 单字标签（「男」「女」）宽 30px 高 22px 时比例才 1.35，配 border-radius:99px 看着仍是个圆。 故 .cp / .ch 取 min-width:44px + 左右 12px 内边距，实测约 1.8 : 1。 滑卡是唯一例外，故意比正文边距宽一档。
按钮颜色是有语义的，不是审美选择。全 App 锁死四级： 海蓝实心 = 主线免费动作（捞瓶 / 抛瓶 / 登录 / 签到领币）· 粉实心 = 要花金币或真钱（解锁 / 打招呼 / 送礼 / 充值）· 灰描边 = 次要动作 · 警示实心 = 破坏性（举报并拉黑）。 花币的次要动作用粉描边，保证「粉 = 要付费」这个信号在任何层级都成立。 渐变只用于品牌面（头图 / Tab 选中块 / 进度条），按钮一律实色。 直接结果：海洋首页的内容区整片不出现粉色——这不是巧合，是在告诉用户「海里免费」。 底部 Tab 的选中药丸是唯一的例外：它属于全局外壳而不是"海"， 选中态用品牌色是所有 App 的通用约定，用户读它是"我在哪一页"，不会读成价格。
Tab 图标不用 emoji。emoji 自带颜色，压在彩色选中块上会很脏； 未选中要靠 grayscale + opacity 灰掉，结果是一团没有形状的糊。 而且同一个 emoji 在不同机器上字形不同——本页开发过程中 🖼 就在测试机上渲染成了方块。 现在统一成一套线性 SVG（文档顶部 <symbol> sprite，全站引用同一份）， 未选中 stroke-width:1.7 取 --ink3，选中 2 取白色。 图标语汇跟着产品走：海洋是三道波、发现是罗盘、动态是四角星。

状态校验

发码闸门

Gestures & motion 🆕 前端专属

静态图标不出手势和时长，每个人就会各拍一个，最后整个 App 的节奏是碎的。 这里给 Flutter 侧可直接落值的参数。统一原则：响应用户动作的动画要快（≤300ms），自动播放的装饰要慢且可关。

场景手势 / 触发动画要点
C1 滑卡 水平拖拽，位移 > 屏宽 25% 或甩速 > 800 px/s 判定成立；否则回弹 跟手 1:1，旋转 = 位移 × 0.06°（上限 12°）；飞出 easeOutCubic 280ms，回弹 spring(0.6, 18) 判定阈值要位移与速度双通道，只看位移则快速轻扫失效，只看速度则慢速长拖失效
C1 印章 拖拽过程中实时显隐 opacity 随位移线性映射 0→1，在 25% 处到满 阈值处到满不透明，让用户松手前就知道结果——这是滑卡最关键的反馈
B1a 捞瓶仪式 按住「捞一个」并下拖 > 30pt 触发；中途松手则瓶子沉回，不扣次数 涟漪 2.6s ease-out 三环错相；瓶子上浮 rise 2.6s ease-in-out； 松手后瓶身放大淡出 220ms，信纸 scaleY 0.3→1 easeOutCubic 340ms 按下瞬间就发请求，动画与网络并行。2.5 秒足够覆盖弱网，用户感知不到加载—— 这是把"加载态"藏进"仪式感"的标准做法
B1 海面可点 点瓶子出气泡；下拉 > 60pt 涨潮刷新；点灯塔进海况 气泡 spring(0.7,20) 240ms 从瓶口弹出；涨潮 = 海平面 translateY 上移 12pt 后回落 气泡不消耗捞瓶次数。首页每天开十几次，必须有零成本可玩的东西，否则只剩两个按钮
B1 抛瓶 点「扔一个」后 抛物线 easeOutQuad 600ms + 落水涟漪 400ms，随后瓶子缩小淡出 这是仪式感动画，全程不可阻塞：接口失败要能中途切错误态，不能等动画放完
B1 瓶子浮动 自动循环 bob 4.5s ease-in-out infinite，各瓶随机相位偏移 必须响应 prefers-reduced-motion；相位不打散会出现整齐划一的「军训感」

抛瓶入水B2 点「抛向大海」一声闷响 + 短涟漪尾音，约 500ms 与抛物线动画的落点对齐，早或晚 100ms 都会"脱手"
瓶子上浮B1a 按住期间低频气泡音，随拖拽位移升调 随手势变化的音高是这 2.5 秒张力的一半。松手瞬间截断
开瓶B1b 松手软木塞「啵」+ 纸张展开的窸窣，约 400ms 这是整个 App 的标志音，值得单独找人做。像微信的"叮咚"
收到回信前台收到 bottle_reply单颗水滴，约 200ms 与系统通知音区分。同一秒内多条只响一次
送礼H4 送出按礼物档位分三档，188 币的带一段和弦 连送 ×10 合并成一次，不叠播
滑卡C1 飞出极轻的风声，−34dB，120ms 可有可无。连续滑动时只播每第三次，否则很吵
不做的：按钮点击音、Tab 切换音、输入键盘音 —— 这些交给系统，自己做只会打架。
唯一一条硬性要求：所有自动播放的动画（瓶子浮动、灯塔闪烁、骨架呼吸、礼物特效） 必须在系统「减弱动态效果」开启时降级为静态。这既是 App Store 无障碍审核项， 也是本页 CSS 已经做了的事（见 @media (prefers-reduced-motion:reduce)）——Flutter 侧对应 MediaQuery.disableAnimations。
