Sign in / Sign up

单屏切换登录与注册，注册成功即登录直接进首页。MVP 不发验证邮件、不做找回密码。

接口
POST /api/auth/email/register
POST /api/auth/email/login
两者均带打包写死的 appid 用于定租户
状态
  • 提交中 — 按钮 loading，字段禁用
  • 1001 邮箱已注册 / 格式非法 → 字段下方红字

合规
Terms / Privacy 链接必须可点 上架必需

Chats spec 缺口

会话列表。不在已确认的五屏内，是我画原型时发现的缺口——没有它，用户退出聊天后永远回不到该会话。

接口
GET /api/chat/list —— 后端已有 ListChatsWithPartner，无需新增
成本
前端一屏（列表 + 未读角标）；后端零改动。约占 MVP 前端工作量 8–10%
替代方案
把会话列表并入 S2 首页下半部分，Tab 减为 Home / Me 两项。不加屏，但首页职责变重
需决策
收进 MVP / 并入首页 / 不做（接受会话不可回访）

动画清单与 Flutter 实现对照

animation spec

左侧参数直接取自 ocean.vue 的 @keyframes，实现时照抄时长与缓动即可保证与小程序观感一致。

动画时长 / 缓动作用对象Flutter 实现
bob4.5s ease-in-out ∞海面漂浮瓶子 AnimationController(repeat: reverse) + translateY(−6px) / rotate(±2°)，每个瓶子错开 delay
blink1.2s steps(3) ∞星星、加载省略号 共用一个 controller，各元素用不同 Interval 相位
beam 增强6s ease-in-out ∞灯塔光束 Transform.rotate。原版是静态 −6°，此处改为扫动——属超出小程序的增强
lamp 增强3.2s ease-in-out ∞灯塔灯 BoxShadow 模糊半径插值，做呼吸感。同为增强项
ripple1.6s ease-out ∞ ×3
delay 0 / .5s / 1s		打捞涟漪 CustomPainter 画三个圆，或三个 ScaleTransition 配 Interval
cast1.6s ease-in-out ∞打捞钩子 TweenSequence：translateY −16→59→−16，同步 rotate −8°→6°
rise1.6s ease-in-out ∞打捞上浮的瓶子 与 cast 共用同一 controller，用 Interval(0.5, 1.0) 延后入场
curl0.75s ease-in纸条卷起 AnimatedContainer 插值宽 300→52、高 200→120、圆角 10→999
intoBottle0.6s ease-in forwards纸条塞进瓶子 Matrix4 复合 translate(116,40) + rotate(40°) + scale(0.25) + 淡出
wiggle0.6s ease瓶子摇晃 RotationTransition ±6°，中点 scale 1.05
toss1s cubic-bezier(.4,0,.7,1)投海抛物线 Path + PathMetric 沿轨迹取点，或 TweenSequence 分三段；含 400° 旋转与 scale 1.05→0.45
splash0.7s ease-out
delay 0.85s		入水水花 接在 toss 之后，用同一 controller 的 Interval(0.85, 1.0)
需要修订 spec 的依赖清单

设计文档 §4.3 的依赖表里没有动画库。以上 12 段动画中，toss 的贝塞尔路径与 curl 的多属性插值用纯 AnimationController 写会相当啰嗦。建议补一个 flutter_animate——声明式链式写法，能把这批动画的代码量压下来一大截。要不要加进依赖表，你定。
