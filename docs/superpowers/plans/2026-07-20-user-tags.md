# 用户标签系统 + 后台金币列 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 管理员可给用户打自定义标签、充值成功自动打「付费用户」标签、后台用户列表新增标签列/金币列并支持按标签筛选。

**Architecture:** `model.User` 加逗号分隔 `Tags` 字段（与 `Bottle.Tags` 先例一致）；打标签走新增的 `PUT /admin/users/:id/tags`；充值自动打标签挂在 `pay.HandleCallback` 入账事务里的一条幂等 SQL；前端在 `Users.vue` 加两列 + 编辑弹框 + 筛选框。

**Tech Stack:** Go 1.22 + Gin + GORM（MySQL）+ Vue 3 `<script setup>`。

**Spec:** `docs/superpowers/specs/2026-07-20-user-tags-design.md`

## Global Constraints

- 标签仅后台管理用，C 端不展示、不下发
- `Tags` 字段总长 ≤255 字符（varchar(255)，用 rune 数校验）
- 单个标签 ≤16 字、不得含逗号（前端与后端 sanitize 双重保证）
- 「付费用户」常量：`model.TagPaidUser = "付费用户"`
- 测试风格：项目只有纯函数单测（无 DB 测试基建），DB 交互靠构建验证 + 手动验证
- 运行 go 命令的目录：`server/`（module root）
- 提交信息用英文 conventional commits，与仓库现状一致

```go
		if i > 0 {
			out = append(out, ',')
		}
		for j := 0; j < 10; j++ {
			out = append(out, rune('a'+i))
		}
	}
	return out
}
```

```go
package admin

import (
	"fmt"
	"strings"
	"unicode/utf8"
)

const (
	maxTagRunes  = 16  // 单个标签最大字符数
	maxTagsRunes = 255 // 整串最大字符数(对齐 varchar(255))
)

// sanitizeTags 清洗逗号分隔标签串:trim、去空、去重(保序)。
// 单个标签超长或总长超限返回错误;空串表示清空标签,合法。
func sanitizeTags(raw string) (string, error) {
	parts := strings.Split(raw, ",")
	seen := map[string]bool{}
	out := make([]string, 0, len(parts))
	for _, p := range parts {
		tag := strings.TrimSpace(p)
		if tag == "" || seen[tag] {
			continue
		}
		if utf8.RuneCountInString(tag) > maxTagRunes {
			return "", fmt.Errorf("标签「%s」超过 %d 字", tag, maxTagRunes)
		}
		seen[tag] = true
		out = append(out, tag)
	}
	joined := strings.Join(out, ",")
	if utf8.RuneCountInString(joined) > maxTagsRunes {
		return "", fmt.Errorf("标签总长超过 %d 字", maxTagsRunes)
	}
	return joined, nil
}
```

```js
const tagModal = ref(null)
const tagDraft = ref([])
const tagInput = ref('')
const savingTags = ref(false)

function tagList(tags) { return (tags || '').split(',').filter(Boolean) }

function openTags(u) {
  tagModal.value = u
  tagDraft.value = tagList(u.tags)
  tagInput.value = ''
}

function addTag() {
  const t = tagInput.value.trim()
  if (!t) return
  if (t.includes(',') || t.includes('，')) { flash('标签不能含逗号', false); return }
  if ([...t].length > 16) { flash('单个标签不能超过16字', false); return }
  if (!tagDraft.value.includes(t)) tagDraft.value.push(t)
  tagInput.value = ''
}

async function saveTags() {
  if (!tagModal.value) return
  savingTags.value = true
  try {
    await api.updateUserTags(tagModal.value.user_id, tagDraft.value.join(','))
    tagModal.value.tags = tagDraft.value.join(',')
    flash('标签已保存')
    tagModal.value = null
  } catch (e) { flash(e.message, false) }
  savingTags.value = false
}
```
