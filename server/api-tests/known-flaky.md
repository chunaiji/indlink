# 已知 flaky 用例

格式:每行一条,反引号包住 request 全路径,后跟原因 / 负责人 / 复查日期。
`--allow-flaky` 时按本清单(文件夹级)跳过。

## 响应时间断言(环境性,非代码缺陷)

- `00 准备(登录双用户)` — 登录建用户 + 注册奖励写入,**远程跨网开发库**(<远程开发库>)首次写偶发 >2s,"响应时间<2s"断言间歇失败;功能断言(code=0/token/user_id)始终通过。本机或生产本地库 <50ms 不复现。 — @dev — 复查 2026-07-01(切本地/局域网 DB 后移除)

> 说明:这是 dev-against-remote-DB 的环境产物。联调若用本地或同机房 DB,此项自然消失。不影响功能正确性。
