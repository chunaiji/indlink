### 4. 管理台租户凭证页（查看 + 修改）

**后端改动:** `server/internal/admin/service.go`

```go
type Service struct {
    db        *gorm.DB
    credStore *tenant.Store  // 新增，用于 Reload
}

type CredRow struct {
    ID       int64  `json:"id,string"`
    TenantID int64  `json:"tenant_id,string"`
    Key      string `json:"key"`
    Value    string `json:"value"`  // 明文展示（解密后）
}
ListCredentials(tenantID int64) ([]CredRow, error)   // 解密展示
UpdateCredential(id int64, req UpdateCredReq) error  // 加密保存 + credStore.Reload()
```

- 更新凭证时，只对非空字段重加密；空字段保留原始加密值
- 保存后调 `credStore.Reload()` 使内存缓存立即生效

**后端改动:** `server/internal/admin/handler.go` 新增 2 路由：

```
GET /admin/api/credentials
PUT /admin/api/credentials/:id
```

**Admin 前端:**

- `admin/src/api.js`：新增 `credentials.*`（list/update）
- `admin/src/router.js`：注册 `/credentials` 路由
- `admin/src/views/Layout.vue`：侧边栏加「🔐 租户凭证」导航
- `admin/src/views/Credentials.vue`（NEW）：
  - 卡片列表展示所有凭证（key + 脱敏值）
  - 编辑弹框：输入新值，留空 = 保持原值

**接线:** `server/cmd/api/main.go`：`admin.New(db, credStore)`（原为 `admin.New(db)`）

## 架构备注

- `Collection` 表 `target_type` 字段为扩展预留：当前只有 `bottle`，后续可收藏用户/动态
- 管理台 Service 的 `defaultTenantID()` 简化了多租户 Admin：SaaS 场景下 `/credentials` 支持传 `?tenant_id=` 覆盖，不传取第一个活跃租户
- `credStore.Reload()` 是同步操作，依赖 `tenant.Store` 已在 main.go 初始化时注入
