## 一、事件根因修复(详见 L3)

uni vue3 alpha + mp-weixin 端 `@tap="方法名"` 裸引用不触发,全站 36 处改为 `@tap="fn($event)"` 调用表达式,所有按钮恢复响应。根因分析见 `l3/2026-06-21-mp-tap-not-binding.md`,规则沉淀见 L4 模式 MP-1。

## 二、海洋页 1:1 复刻(纯 CSS/emoji,无 SVG)

- 顶部:`筛选` / `漂流瓶` 标题 / `•••`+头像;情绪钩子 `今日已有 N 条回应`(青色数字);右侧 `邀请好友领回应` 悬浮胶囊。
- 夜景:深蓝渐变 + 22 颗固定星点 + 月亮辉光;**CSS 灯塔**(红白塔身 `clip-path` 梯形 + 发光灯室 + 光束三角锥)+ 海岛/山丘剪影。
- 海面漂浮瓶子:用真实照片 `static/bottle-l.png`/`bottle-r.png`(用户提供,中文名 `左/右.png` 拷贝改 ASCII 名),按索引奇偶交替朝向,轻摇 `bob` 动画 + 回应数角标。
- 沙滩三件事:`扔瓶子`/`捞瓶子`(青色高亮)/`我的瓶子`。

## 三、捞瓶子:信纸弹框 + 打捞动画

- 点「捞瓶子」→ 先播 **1.6s 打捞动画**(🎣 反复下沉上提 + 三层涟漪 + 🍾 浮起),期间并行取数,结束才弹信纸。`scooping` 期间锁重复点击。
- **信纸弹框**复刻设计稿:叠纸效果(两层旋转纸背+主信纸)+ 📎 + 圆头像/昵称/`lv` 徽标/💌 + **横线信纸正文**(`repeating-linear-gradient`)+ `时间·城市`/`#标签` + `换一个`/`查看详情`。
- **长文兼容**:正文用 `scroll-view` 限高 `44vh` 可滚动,`word-break+pre-wrap`,头尾固定 —— 修了"长文撑爆界面遮挡"的问题。
- 数据走现成 `bottleApi.scoop` 缓冲池,`换一个` 取下一只,`查看详情` 进详情页。

## 四、扔瓶子:写纸条 → 卷起 → 塞瓶 → 投海(弹框)

- 「扔瓶子」不再跳页,弹出**写纸条**(米黄横线纸 + 📎 + textarea + 快捷标签 + 匿名开关 + 字数),按钮 `封瓶投海`。
- 提交成功后三段 CSS 动画:`roll`(0.75s `curl` 纸卷起)→ `stuff`(0.6s `intoBottle` 纸卷钻进 🍾)→ `toss`(1s 抛物线翻转入海 + 💦)→ 关闭/刷新海面/toast。动画中禁止点遮罩关闭;创建失败(2003 未实名)只提示不播动画。

## 五、我的瓶子(新页 `pages/mybottles`)

- 「我的瓶子」从错误的 `switchTab 到我的` 改为进入新列表页。
- 筛选 `全部`/`有回应`(带数字角标);卡片:状态徽标(漂流中/已过期,按 `status` + `expire_at` 计算)、内容摘要(3 行)、`#标签`、`💬N 回应`(有则高亮)、`❤️N`、展开。
- **点卡片展开** → 拉 `GET /:id/replies`(作者身份后端自动解锁回应)→ 列出每条回信。空状态引导去扔瓶。
- 全用现成接口 `bottleApi.mine` + `bottleApi.replies`,**后端零改动**。

## 六、收尾

- **删除旧 `pages/throw` 页**:`pages.json` 注册移除 + 文件/目录删除 + 产物无残留;唯一外部入口(我的瓶子空状态"去扔一个")改为 `setStorageSync('pendingCompose')` + `switchTab 海洋`,由海洋 `onShow` 读取标记自动弹写纸条框 → **入口统一**。
- **emoji 豆腐块清理**:全项目审计,移除 Emoji 12+ 易豆腐块的 `🪙×6`(改纯文本"金币/币")、`🪣×1`(海洋"我的瓶子"改 `🍶`);其余老码点 emoji 渲染正常予以保留。规则见 L4 模式 MP-2。
